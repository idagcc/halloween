PUMPKIN POP! — HALLOWEEN ARCADE

START
Double-click index.html to open the game in Chrome, Edge, or Safari.
No installation or internet connection is needed. All graphics and sounds
are built into that one file. Copy index.html to the event computer by USB.

AT YOUR EVENT
Connect the event computer to your 4K TV. Set the display to 3840 × 2160
and browser zoom to 100%. Press F or the fullscreen button.
The entire game stays in a strict 16:9 frame. Other window shapes show
centered dark bars without stretching or cropping the game.
Enter a first name and press “Play” Only the first word entered is used. A touch-friendly on-screen
keyboard is available beside the name field. After the round, choose
“Next player” to clear the name for the next child.

HOW TO PLAY
Tap pumpkins and ghosts for 10 points. Golden pumpkins are worth 30.
The carnival backdrop contains no static ghosts or pumpkins.
Targets appear in random positions and disappear after a short time.
There are no penalties or losing screens. Multiple simultaneous touches
are supported. A mouse or touch sensor that sends mouse clicks also works.

SETTINGS
Every round lasts 60 seconds. Choose Big or Extra big pumpkins, Gentle
or Speedy pace, and the full play area or lower half for easier reach.
The defaults are Big pumpkins and Gentle pace.
Use the speaker button to toggle the generated sound effects.

TV / SOFT BALL INPUT
A regular TV displays the game but does not detect hands or balls.
Use a touchscreen overlay or interactive sensor that sends standard touch
or mouse events to the computer. Ball play requires a compatible sensor
and a display/setup approved for that activity.

PAUSING
Use the pause button or Escape. Switching away from the game pauses it.
The timer resumes from the same point. Fullscreen is a separate F shortcut.

SCORES AND PRIVACY
The end screen shows the score, top five leaderboard, and current player rank.
First names, scores, and settings are stored only in the current browser
when local storage is available. Leaderboards compare the same round length.
File-based storage behavior varies by browser; keep using the same browser
and file location for the event. No information is sent anywhere.

The moonlit carnival artwork was cleaned of static characters and is embedded
in index.html. Pumpkins and ghosts appear only as interactive game targets.
No external libraries, services, fonts, analytics, or network requests.

The mouse pointer is hidden throughout the countdown and gameplay, including
when a touchscreen sensor sends mouse clicks. It returns on pause and menus.

LEADERBOARD AND MUSIC
Scores are saved locally under the storage key pumpkin-pop-records. The Mac
app and each browser keep separate scores; builds do not contain player data.
To remove test scores, open the trophy button on Home, choose Clear leaderboard,
then Delete all scores. This removes all scores on that device and cannot be undone.
Settings offers Halloween music: Off, Soft (default), or Normal. The original
minor-key tune plays during countdown and rounds, stops on pause and menus,
and works offline. The speaker button mutes both music and sound effects.
